# 对比检查报告：Celestron EdgeHD 系列使用说明书（demo.pdf）→ demo_SimplifiedChinese.pdf

- 原文：`demo.pdf`（21 页，612×792pt，**Celestron EdgeHD 系列英文说明书**）
- 译文：`demo_SimplifiedChinese.pdf`（21 页，同尺寸，**原位翻译**）
- 体检命令：
  - `python check_translation.py "demo.pdf" "demo_SimplifiedChinese.pdf" --lang "Simplified Chinese"` → exit 1（3 页告警，其中 **2 页为误报**，见 §7）
  - `python check_layout.py "demo.pdf" "demo_SimplifiedChinese.pdf"` → exit 1（**4 处重叠 + 1 处字号过小**）
- 另用 PyMuPDF 逐页渲染对照、比对 span 坐标/颜色/旋转、并抽查页内所有文字块。

- 译文总字数约为原文的 32%（中文更紧凑），抽检 p17、p20 等"比值偏低"的页确认**没有丢内容**。

| 类别 | 位置 |

## 1.【需修】4 处文字互相重叠（check_layout 全部报出，已逐条复核坐标与截图）

四条都是同一个病：**同一基线上画了两段互相覆盖的文字**。

| 页 | 重叠率 | 叠在一起的两段 | 坐标 |
| --- | --- | --- | --- |
| 10 | **100%** | `使用相机的包围曝光功能自动改变曝光时间，以找到最` × `佳曝光。` | 两段**同为 y=191.2、同为 x=103.6 起** |
| 20 | **100%** | `注：` × `本质保仅适用于从美国或加拿大授权星特朗经销商处购买本产品的…` | 两段**同为 y=600.5、同为 x=90.0 起** |
| 4 | 34% | `1. 天顶镜上。` × `后座中。松开天顶镜上的紧定螺丝，直到螺丝尖端不再伸入目镜端的内径` | 同为 y=115.3，x 重叠 90.0–108.5 |
| 15 | 61% | 标题 `望远镜 维护`（24.8pt / 21.4pt） × `望`（17.3pt） | 同为 y≈95.4–97.4 |

**截图确认**：
- p10 渲染出来的第 5 步是「5. 使**曝**相机的包围曝光…」——"用"字被换行后的续行「佳曝光。」压住；
- p15 大标题「**望**远镜 维护」上多叠了一个「望」。

**成因**：换行/分块后的续行被画回了**第一行所在的位置**（p10 两段 x 起点完全相同），而不是下一行的 y；p20 是段落被重新排版后左边界从 x=126 挪到了 x=90，与同行的 `注：` 撞上。

## 2.【需修】数字与百分号被换行拆开（p15）

译文中出现：

```
…一种好的清洁液是异丙醇与蒸馏水的混合液，比例为60%异丙醇和40
%蒸馏水。…
```

源文 `60% isopropyl alcohol and 40% distilled water` 的 **`40%` 被断成 `40` + `%蒸馏水`**（断行断在了数字和百分号之间）。这会让读者/解析器把"40"和"%"分开读，也正是 check_translation 报"原文 1 次「40」在译文中缺失"的原因。

全文扫描：`\d\s*\n\s*[%℃°]` 只命中 p15 这一处，属孤例；建议在换行算法里加一条"数字与其后的 %/单位不得断行"的规则。

## 3.【需修】图内文字（image_text）把 logo 认成乱码、图注却没翻译

### 3.1 封底 Celestron logo 被 OCR 成乱码后画在 logo 上（p21）

| | 内容 |
| --- | --- |
| 源文 | 封底只有一张 logo 位图（CELESTRON 圆形标 + 字标），页面上没有对应文字 |
| 译文 | 文字层多出 `CELL LESTR` 与 `℞N`，并**直接画在 logo 图形上** |

渲染结果：封底 logo 被切成「(C)  `CELL LESTR`  `℞N`™」——**品牌标识被破坏**（原来的 CELESTRON 字标被白色覆盖块和乱码字符切断）。

### 3.2 图注被 OCR 重画但**没有翻译**（p3、p14）

- p3 图 1-1 / 1-2 的标注以英文原样出现在中文页面里：`1.25" Eyepiece`、`1.25" Star Diagonal`、`Visual Back`、`2 inch Eyepiece`、`2" Mirror Diagonal`；
- p14 的 `CCD Camera` 同样未译；标题 `Fastar L ens Assem bl` 则是把源文自身的错空格原样搬了过来（`Fastar Lens Assembly` 未被正确翻译/纠正）。

结果就是**同一页上正文是中文、图内标注还是英文**。

## 4.【轻微】封面主标题描边丢失（p1 变浅灰）

| | `EdgeHD Series` / `EdgeHD 系列` |
| --- | --- |
| 源文 | span 填充色 `0xC0C0C0`，但实测区域内最深像素 **(0,0,0) 纯黑** → 源文是"灰填充 + 黑描边"（伪粗体） |
| 译文 | 填充色同为 `0xC0C0C0`，实测最深像素 **(192,192,192)** → **黑描边丢失**，只剩浅灰 |

封面主标题因此明显比原文淡（渲染图上"EdgeHD 系列"呈浅灰、发虚）。副标题 `使用说明书` 是纯黑 `0x000000`，两边一致。

## 5.【轻微】术语与版式细节

1. **collimation → "对光"**（p17 等多处）。业余天文领域通译是"**光轴校准 / 准直**"；"对光"在中文里一般指显微镜的照明对中，容易被误解。
2. **p21 封底地址/版权块的多行结构被合并**：源文 6 行（`Celestron` / `2835 Columbia Street` / `Torrance…` / `Tel. …` / `Fax. …` / `Web site at …`）在译文里并成 4 行，出现 `星特朗 2835 Columbia Street`、`保留所有权利。（…）编号 #91030-INST $10.00` 这类"把编号粘到上一段"的合并；URL 也从源文的 `http//www.celestron.com`（源文本身少一个冒号）写成 `http:/www.celestron.com`。
3. **p10 有 5.0pt 的文字**（`目视后部`，源文 8.0pt），低于 6.3pt 的可读下限。

## 7. check_translation 的 3 条告警：2 条是误报

| 页 | 告警 | 判定 |
| --- | --- | --- |
| 8 | 原文 1 次 `1000` 缺失；译文多出 2 次 `0.9` | **误报**。源文写 `1,000 yards`（带千分位 → 被计为金额）与 `.9°`（无前导零 → 不被识别为数字）；译文写 `1000码` / `0.9°`（中文里更规范）。检查器的"裸整数不计"规则与"必须有前导零"规则造成假红。 |
| 19 | 译文多出 1 次 `936449` | **误报**。译文 `8英寸用#93644，9/11/14英寸…` 中，全角逗号 `，` 被正则当成千分位分隔符，把 `93644，9` 读成一个大数。 |
| 15 | 原文 1 次 `40` 缺失 | **真问题**，即 §2 的"数字与 % 被换行拆开"。 |

## 8. 优先修复建议

1. **换行续行的落点**：换行后的第二行必须画在 `y + 行高`，不能画回第一行的 y（§1 的 p10 / p20 是最典型的两例）；重新排版时也要避免把段落左边界挪到与同行标签冲突的位置。
2. **禁止"数字 + %/单位"断行**（§2）。
3. **图内文字要有"该不该重画 + 该不该翻译"的判断**（§3）：
   - logo/品牌字标这类图形文字**不要 OCR 重画**（p21 的乱码把品牌标识毁了）；
   - 图注要么整体翻译、要么整体保留，不能中英混排（p3 / p14）。
4. **保留源文的文字渲染模式**：源文用"填充+描边"伪粗体的标题，译文应一并还原描边（§4）。
5. **术语表补录**：`collimation → 光轴校准`（§5）。
