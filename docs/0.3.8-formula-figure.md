# 0.3.8 公式占位 · 图注/图理解细化方案：让「公式不被改坏、图注译得准」

> 版本：v0.3.8（草案）　　状态：待定稿　　上一篇：`0.3.8-方向设计.md`（档位 B-⑤）、`0.3.8-semantic-parse.md`（档位 B-④）
>
> 对应方向档位：**B-⑤**。本文把「公式识别并占位（绝不改写）、用 VLM/渲染帮 AI 看懂图与图注、新增 formula/figure 分型与特殊页协商」细化成可落地、可回退的方案。**依赖与前置**：语义类别由 **B-④** 的 `Block.kind`/`structure_protect` 给出；本方案同时提供**无 B-④ 时的几何回退检测**（`_is_formula_block` 启发式），保证主路径不开 B-④ 也能防「公式被改坏」。

---

## 1. 一句话目标

两件事：
1. **公式占位**：把公式识别出来、作为**结构保真块（`structure_protect`）**在翻译里**占位、绝不改写**——公式是数学内容不是散文，翻译它必然变异或错位。周围文字（公式编号、说明、表注）照译。
2. **图注/图理解**：把图区识别出来（`kind="figure"`），让 agent **翻译图注**但不「改写图本身」；当图注含术语、图内文字需要转译时，用 `render_page` 让 AI 先「看」图再译，提升图注准确性。

解锁场景：**科学论文 / 带公式与图的文档**——正是 PDFMathTranslate 的立身场景，也是本项目当前最明显的功能空缺。

---

## 2. 现状与问题

| 问题 | 现状 | 后果 |
|---|---|---|
| 公式被当散文翻译 | `_needs_translation` 只看「是否有字母」，公式文本（含变量/单位/运算符）被送进模型 | 公式语义被改写、版面错位，破坏数学正确性 |
| 无公式/图分型 | `classify_page` 只返回 normal/scan/chart/uncertain | 公式页/图页不进入特殊页协商，AI 无从知道「这页是公式」 |
| 图注翻译靠猜 | agent 只读图注文本、不「看」图 | 图内文字/方向/缩写对应不上，图注译错 |
| 图内文字缺失 | 图注常引用图内标注（A/B、坐标轴、单位） | 孤立译图注易错 |

---

## 3. 数据与检测

### 3.1 公式检测（两级）
- **B-④ 语义后端**：`Block.kind == "formula"`（DocLayout-YOLO/MinerU 给出的公式区域），高置信。
- **几何回退**（不开 B-④ 时保住底线）：`pdfio._is_formula_block(block)` 启发式——块内**无中文、高宽比异常、含公式典型字符**（`= + − × ÷ Σ ∫ √ ∞ ^ _ frac` 等）或**多为符号/单字符**、或字号与正文差异大的孤立窄高/跨行块。**保守**：宁可少判（不把普通文本误判为公式），判不到就走翻译；判到就走占位。
- `_is_formula_block` 与 `_is_vertical_label` / `_is_numeric_cell` 并列，同为模块级单一来源（供翻译跳过 / 审计保护 / 导出器共享）。

### 3.2 图检测
- **B-④**：`Block.kind == "figure"`（区域框）。
- **几何回退**：块位于图区上方/下方、字号小、含「图/Fig./Figure/Table/表」前缀，或所在的页 `classify_page` 判定为 chart/图页。
- 图注块（caption）单独标记 `kind := "caption"`（可译），图区本体区域标记 `structure_protect`（块内若被 OCR 出文字，按需转译、不按散文改）。

---

## 4. 管线落点

### 4.1 受保护门（公式/图不被改写、不被报残留）
- `agent.flow._audit_protected` 并入 `structure_protect`（B-④ 语义）+ `_is_formula_block`（几何回退）：公式块视为**已保真**——`check_residual`/`audit_page` 不再对它们报「未译」。
- `translator._needs_translation`（或批量选择的 `_pick_translatable` predicate）跳过公式块：**不送模型、不写缓存**，原文原样保留。
- `prompts.page_task` / `agent_tool_policy` 增补规则：「公式块 `structure_protect`/公式——保留原文，译文里是数学性的原文；图注需翻译，图内容若需转译可 render_page 看图」。

### 4.2 特殊页协商（新分型）
- `classify_page` 增 `formula` / `figure` 分型（B-④ `kind` 支持；几何回退按公式/图比例判定）。
- `prompts.special_page_question(page, kind)` 增 `formula`/`figure` 分支：`figure` → 「保留原文 / 翻译图注 / 跳过」；`formula` → 「保留原文 / 翻译公式说明 / 跳过」。
- `DocumentSession._interpret_answer`（`make_llm_interpret` / `_classify_choice`）同步新选项映射。

### 4.3 图注/图理解（视觉闭环）
- 复用现有 `render_page`：把图所在页渲染给模型（`make_llm_decide` 已把带 `image` 的结果作为新的视觉观察注入）。
- 为省 token / 聚焦，**可选**扩展 `render_page` 支持 `region=[x0,y0,x1,y1]` 裁剪（或新增一个已绑定的 `render_region(page, bbox)`），仅渲染图区域。**注意「先绑定后暴露」铁律**：要么把 `render_region` 真实绑进 `make_page_executors` 并让结果进入视觉观察，要么不做，绝不暴露「调了没效果」的工具。
- 图注翻译：agent 先 `render_page`（或 `render_region`）看图 → `translate_block` 译图注 → 若图内文字需转译，可用 `apply_annotation`/`set_text` 处理图注，仍以不破坏图形为准。

---

## 5. 安全 / 门槛

- **保守优先**：公式/图检测要**保守**——宁可少判（普通文本照常翻译），不可误判（把公式当散文改坏、或把整页当公式页跳过）。误判风险在于「牺牲可译性」，底线高于「错判公式」。
- **不改导出几何**：公式/图块仍按 bbox 绘制；公式占位即「在该位置放原文」，图区保留原图。
- **可选、可回退**：公式/图保护在**不开语义后端**时靠 `_is_formula_block` 几何回退生效；该启发式若对某页无效，则该页按普通文本处理，不静默吞掉。
- **audit 不误报**：公式/图块被排除在 `check_residual` 的「未译」之外，避免把「保留原文」报成残留（与既有 `is_chart`/`_protected` 处理一致）。

## 6. 分阶段实施计划

| 阶段 | 内容 | 验证 | 状态 |
|---|---|---|---|
| **1** | `_is_formula_block` 几何回退 + 并入 `_audit_protected`/`_pick_translatable`/`_needs_translation`；公式块翻译跳过 | `test_pdfio`/`test_translator`：公式块不被送模型、原文保留、非公式正常译 | ⬜ 未启动 |
| **2** | `classify_page` 增 `formula`/`figure` 分型 + `special_page_question`/`make_llm_interpret` 同步 | `test_pdfio`/`test_session`：公式/图页进入协商，选项映射正确 | ⬜ 未启动 |
| **3** | 图注识别（`kind="caption"`）+ 图注翻译规则注入 `page_task`/`agent_tool_policy` | `test_agent`：图注被译、图本体不被打散 | ⬜ 未启动 |
| **4** | `render_page` 支持 `region` 裁剪（或 `render_region`）——图理解视觉闭环 | `test_agent`：看图后译图注；`render_region` 已绑定且结果进视觉观察 | ⬜ 未启动 |

> **建议**：**1** 最小可用（保住「公式不被改坏」的底线，且无需语义后端）；**2** 让公式/图页进入人机协商；**3 + 4** 是图注/图理解的增强，可与 B-④ 并行。每阶段以 A-② 的 `--pdf-only`/num 指标确认**未引入数字/版式回归**。

## 7. 未决问题

- **公式检测精度**：`_is_formula_block` 几何启发式误判率？在样例（含公式/不含公式的科学文档）上先测阈值，避免把「公式说明文本」也吞掉。
- **公式占位 vs 公式转译**：是否**永远保留原文**（最稳），还是目标语为西文时尝试把变量名/单位按规则保留、只译说明？倾向：**公式本体绝不改，说明/编号照译**。
- **图内 OCR 文字**：扫描图内文字是否要 OCR + 转译（B-④ 的 OCR 结合）？当前倾向**不转译图内文字**（破坏图形），只译图注；图内关键文字经 `render_page` 让模型在图上理解、不落回文本。
- **`render_region` 的绑定**：是否新增（需真实绑定 + 视觉注入，见铁律）还是复用整页 `render_page`（省事但 token/聚焦成本高）？
- **图注是否算「受保护块」**：图注需翻译，而 `structure_protect` 已有保护语义——需用 `kind="caption"` 与图本体（`structure_protect`）区分开，避免把可译图注也禁改。
- **提示词疏导**：`page_task` 已强制「整页全译成目标语言、不得提前结束」——如何让模型「公式/图保留原文」不被这条规则判为「未译完全」？需要在提示词里显式声明「公式/图块不属于漏译」（与既有 `_protected` 的注记同思路）。
