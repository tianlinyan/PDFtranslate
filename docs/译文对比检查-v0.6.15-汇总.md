## 一、共性问题（跨样本）

### C1 文字互相叠印（同一基线上两段文字）——**4/4 命中，最高频**

| 样本 | 证据 |
| --- | --- |
| Beyond | 14 处：p2 41%（`0.14），表明决策边界…` × `训练遵循"超饱和"协议：`）、p8 53%/80%、p25 99%/84% |
| Mintai | p27 两处（长标签越过"行次"列；金额压住 `Head of Accounting`） |
| Evergrowing | p4 `·`×`2025`（左页边原文与残缺译文叠压） |
| demo | p10 **100%**（续行 `佳曝光。` 画回第一行的 x/y）、p20 **100%**（`注：` × 正文）、p4 34%、p15 61% |

**三类根因**：① 换行续行被画回第一行位置（demo p10/p20）；② 单行块不换行、中文比英文长导致横向溢出到邻栏（Beyond p2/p8）；③ 段落重排后左边界挪动，与同行标签/编号相撞（demo p4/p20、Mintai p27）。

### C2 图内文字（image_text）处理不当——**4/4 命中**

| 样本 | 证据 |
| --- | --- |
| Beyond | p1 图 1、p3 图 4：白底矩形**盖住柱状图**；p5 旋转刻度被水平重画成 `10-120-450-100=209`；y 轴标签被拆成 `概`/`率`；同一张图**半译半不译** |
| Mintai | 封面：顶部行标只盖住字的下半（中文笔画残影）；照片横幅**黑字压白字**、不可读 |
| Evergrowing | logo 蓝块内译文折行溢出，白字落到白底**不可见** |
| demo | 封底 logo 被 OCR 成 **`CELL LESTR`** + `℞N` 并画在 logo 上，**品牌标识被切断**；p3/p14 图注重画却**未翻译** |

**共性根因**：图内文字被当作正文"OCR → 翻译 → 重画"，但缺少三条判断：**该不该重画**（logo/字标不该）、**该不该翻译**（图注应整图统一）、**旋转要不要保留**（要）。

## 四、解决方案

### P0 —— 正确性（数据错了就是事故）

**S1 扫描页数值兜底校验（补住最大盲区）**
- 现状：`check_translation.py` 对无文本层页**整页跳过数字比对**，Mintai p27 的 `-5,138,116,000 → 5,138,116,000` 因此漏检。
- 做法：无文本层页 → 对该页做一次 OCR 取数（复用 `_get_ocr_engine`），与译文文本层逐格比对；**符号（`+`/`-`/括号负）单独成项比对**，整数位数变化一律报错。
- 落点：`check_translation.py` 新增 `_check_scanned_page_numbers`；导出侧 `pdfio._build_table_blocks` / `_reconstruct_ocr_grid` 在写入 `Block.text` 前对"负号丢失"做一次断言。
- 验收：Mintai p27 应报出该条；四份样本的扫描页无一漏报。

**S2 专有名词锁定与实体校验**
- 导出前扫描译文，凡是"机构名/公司名/表号"形态的实体，必须能在源文（或其术语表映射）里找到来源；出现源文中不存在的机构名即报错。
- 把 `浙江民泰商业银行 / 民泰银行 / 会商银xx表`、`Hengfeng Bank`、`Celestron/星特朗` 等写入 `glossary.json` 或系统提示词白名单。
- 验收：Mintai 的 `Xinjiang Minquan Commercial Bank`、`Huishang Bank Form` 不再出现。

**S3 导出前的"叠印不变量"断言**
- 规则：**同一 y 带（重叠 > 40%）内不得存在两段互不相同的文字**（旋转文字按旋转帧判定）。
- 现状：四份样本都有，且 `check_layout` 事后能抓到——把它前移成导出前的自检，命中即拒绝导出并给出坐标。
- 验收：demo p10/p20、Beyond p2/p8/p25、Mintai p27、Evergrowing p4 全部被拦下。

**S4 数字与其单位/标点"不可断行"**
- 断行单元：`数字+%`、`数字+℃/°`、`数字+单位词`、`编号#xxxxx`、`千分位数字整体`。
- 同时修正英文输出的"逗号后补空格"（`April 30, 2026`）。
- 验收：demo p15 不再出现 `40` / `%蒸馏水` 断行；Mintai 的日期不再被读成 `302026`。

### P1 —— 版面结构

**S5 列聚类加固（一处修复解决 Beyond 大半问题）**
- `_order_generic`：整宽判据不要用 `0.75 × 页面跨度`，改为"**跨过两个列带**"或"宽于任一栏"；并约束 `col_max_x1`——**不允许某个块把列右边界扩到页面右缘**。
- 预期收益：Beyond p1/p2 恢复 2 栏 → 单行块从 89% 降回正常段落粒度，同时消除 C1（横向溢出）、C3（硬断行 + 断字连字符）、p8 表 3 题注错位、p12 "漏画"。

**S6 对齐判定修正**
- 单行块不要仅凭"右边缘贴页右边界 + 起点过中线"就判 right；要求**块自身 bbox 右对齐**（x1 贴右边界且 x0 明显偏右），并对"齐左 + 齐右（两端对齐）"单独识别为 left。
- 验收：Beyond 的 182 个右对齐块归零，第 11/12 页参考文献不再参差。

**S7 旋转/竖排文字：保留源方向、全页擦除**
- 绘制方向必须沿用源 `dir`（Evergrowing 的 (0,1) 不能被改成 (0,-1)）；
- 旋转块的**擦除要覆盖所有页面**，且原文必须擦干净再加译文（Evergrowing p4 左页边漏擦 + 叠加）。
- 验收：Evergrowing 四页页边文字方向一致、无重复；Beyond p5 旋转刻度按原角度绘制。

**S8 图内文字策略（C2 的总闸）**
- **不重画**：logo、品牌字标、印章、照片上的字（demo 封底、Mintai 封面、Evergrowing logo）；
- **整图统一**：一页/一图内的标注要么全译、要么全保留，禁止半译（Beyond 图 1、demo p3）；
- **旋转保留**：OCR 出的旋转文本按原角度绘制（Beyond p5、Evergrowing 页边）。
- 白底矩形必须**贴合实测字形带且不越出原文字形**；照片区域"不画白底也不重画"。

### P2 —— 保真与观感

**S9 表格样式保真**：线色/线宽/行底纹从源表读取（Evergrowing 蓝线→黑线、底纹丢失）；列边界尽量沿用源列位置。
**S10 字号一致性 + 可读下限**：按**列/行**而非单格定字号（Evergrowing `Male`/`Female`、Mintai 表头 6.8 vs 3.7pt）；低于 5pt 触发换行重排或扩页（Mintai 3.07pt）。
**S11 文字渲染模式保真**：源文用"填充+描边"伪粗体的标题，译文一并还原描边（demo 封面标题）。
**S12 文本层规范**：导出后检测 U+0000/替换字符并报警（Beyond 2 个）；全角拉丁字母统一转半角（Evergrowing、demo）。
**S13 术语表**：`collimation → 光轴校准`、`star diagonal → 天顶镜`（后者已正确）等。

### P3 —— 检查工具自身

**S14 数字比对规则修正**（当前 4 份样本里误报占比很高）：
1. 全角逗号 `，` **不得**作为数字内部分隔符（Beyond p10/p12/p19、Mintai、demo p19 的 `936449`）；
2. "括号 = 负数"启发式限定**会计场景**（Beyond p4 `(+71%)`、p24 `(0.528)`，Mintai p4/p24）；
3. "裸整数不计"与"必须有前导零"两条规则**方向要对称**（demo p8 的 `1,000`/`1000`、`.9`/`0.9`）。

**S15 新增检查项**：① 同基线文字重叠（已有，建议升级为导出前门禁）；② 文字越出容器（色块/图框）；③ 纯 ASCII 源块未擦除却被覆盖；④ 表格样式保真（线条数/颜色/填充块）；⑤ 数字与单位被断行。

**S16 覆盖率**：目前有大量块"无法对应到原文块"而不参与比对——Beyond 130 段、Mintai 698 段，最小字号 3.1pt。**这些块恰是问题高发区**，应把它们纳入字号/重叠检查。

## 五、修复顺序建议（若只做三件事）

1. **S1 + S2（P0）**——扫描页数值兜底 + 专有名词锁定。这是"会出事故"的两类：财务数字正负颠倒、报告里出现别家银行名。
2. **S5 + S6（P1）**——列聚类与对齐判定。一处改动即可消化 Beyond 样本约 70% 的问题（89% 单行块、14 处重叠的大半、61 处断字连字符、参考文献参差）。
3. **S3 + S8（P0/P1）**——导出前叠印断言 + 图内文字策略。四份样本的"文字互相压住"和"图上乱画"可一次性收敛。
